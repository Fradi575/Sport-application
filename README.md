Ebben a repositoryban található a sportalkalmazás amit Big data technológiák tantárgyra készítettem, és egyben ez a diplomamunkám témája is.
Ez a webalkalmazás a 2024/25-ös férfi labdarúgó NB1-es szezon 12 csapatát mutatja be, elhelyezi a stadionjuk alapján térképen, emellett több
statisztikai adatot is szemléltet a program, különböző diagramokkal (pl a csapatok hazai pályán szerzett és kapott góljai, játékosok magassága, góljainak száma, életkora).
A webalkalmazás a diplomamunkám során folyamatosan frissül, és már elérhető pyqt-ban is.
